## Legenda das colunas

| Coluna                | Significado                                                                                                                      |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ID                    | `MÓDULO-TIPO-NNN`; TIPO ∈ UNID, BANCO, INTEG, E2E, SEG, CARGA, CONC, LEGAL, UI.                                                  |
| Tipo                  | unidade, banco, integração, e2e, segurança, carga, concorrência, legal, ui.                                                      |
| Cenário               | O que é verificado, com a regra (RN/D/PL) quando houver.                                                                         |
| Pré-condições e dados | Estado inicial, papel do usuário e massa de dados.                                                                               |
| Passos                | Chamada de função, consulta ou ação na tela.                                                                                     |
| Resultado esperado    | O que deve acontecer. `HIPÓTESE — confirmar com dono do produto` marca regra não documentada.                                    |
| Invariantes           | IDs de `INV-001` a `INV-020` protegidos pelo teste (tabela abaixo). `—` quando nenhum se aplica.                                 |
| Severidade se falhar  | Crítica (dinheiro, isolamento ou dado legal), Alta, Média, Baixa.                                                                |
| Automatizável         | Sim, Parcial ou Não.                                                                                                             |
| Cobertura             | `Existente: <arquivo>` (teste já no repositório, conferido), `Lacuna` (sem teste) ou `Novo: <arquivo>` (criado nesta auditoria). |
