# QA — Invariantes

> Data: 15/11/2026. As consultas usam **o esquema real** confirmado na auditoria (`00-auditoria.md`).
> **Fonte única executável:** `supabase/tests/auxiliares/qa_invariantes.psql`, com a função `testes.qa_invariantes()` cujo corpo é um único SELECT somente leitura.
>
> - **Nos testes:** `048_qa_invariantes` exige zero violações novas depois de um ciclo completo em duas loteadoras.
> - **Em qualquer banco, inclusive produção:** `scripts/qa/invariantes.sh "<url>"` extrai o mesmo SELECT e roda dentro de `begin transaction read only … rollback`.
>
> Sobre a massa de carga (201.000 parcelas, 287.000 linhas de auditoria), as 22 verificações rodam em **~1 s**.
